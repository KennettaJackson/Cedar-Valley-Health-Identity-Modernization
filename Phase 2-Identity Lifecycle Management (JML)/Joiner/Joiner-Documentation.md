### Acquisition Scenario

Cedar Valley Health acquired a small outpatient clinic and needed to onboard representative employees into the existing Microsoft Entra ID environment.

### Groups Added for the Acquisition

The following role-based security groups were created:

- CVH-Billing
- CVH-Front-Desk
- CVH-IAM-Team
- CVH-Nurse-Managers
- CVH-Nurses
- CVH-Physicians

### Joiner Process

1. HR provides employee information.
2. IAM provisions the identity.
3. User properties are populated.
4. Appropriate security group membership is assigned.
5. Access is reviewed against the employee’s role.
6. Provisioning activity is verified.
7. Relevant screenshots and evidence are documented.

### Result

The new clinic workforce was successfully represented within the CVH Entra ID environment using role-based security groups.
