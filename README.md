# 📖 Project Overview

This repository documents the identity modernization journey of **Cedar Valley Health (CVH)**, a fictional healthcare organization implementing Microsoft Entra ID and Zero Trust security practices.

The project simulates the responsibilities of a **Cloud IAM Administrator** responsible for designing, securing, and managing an organization's cloud identity environment.

The goal is to demonstrate how organizations mature their identity infrastructure through:

- Identity management
- User lifecycle processes
- Access control
- Authentication security
- Governance
- Automation
